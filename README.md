##  Como Executar o Projeto Localmente

Siga os passos abaixo para rodar a aplicação localmente no seu computador: 

1. **Clone o repositório:**
   ```bash "terminal"
   git clone (https://github.com/NatanSandoval/govdesk-grupo-4)
   cd govdesk-grupo-4

2. **Instale as dependências do projeto:**
   ```bash "terminal"
   pip install -r requirements.txt

3. Execute a aplicação Flask:
    Bash "terminal"

    python app.py

4. Acesse no seu navegador:
    Abra o link http://localhost:8080 (ou o endereço e porta informados no terminal).
